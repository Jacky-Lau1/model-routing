# 10｜未来实施交接说明

当用户要求“把模型路由方案落地”时，执行者必须先做以下恢复动作，不能直接安装或写配置：

1. 阅读本文件、`docs/08-decisions.md`、`docs/06-implementation-roadmap.md`、`docs/05-compatibility-validation.md` 与 `logs/` 最新记录；
2. 检查仓库当前版本、未关闭事件、模型目录状态和决策是否过期；
3. 重新查证 Codex 当前版本对自定义 provider/agent 的支持、模型价格和候选提供商 API；
4. 向用户确认候选提供商、数据边界、预算、目标项目和允许的本机权限；
5. 仅从 Phase 0 开始，记录实验，而不是直接开启全自动路由。

## 不可变护栏

- 禁止提交或展示真实凭据；
- 禁止将整个聊天、私有代码或敏感数据无筛选地发送给外部模型；
- 禁止未经日志证明的静默回退；
- 禁止在未完成验证前声称“全自动可用”；
- 禁止跳过本地质量门或 Sol 最终审查；
- 任何生产发布、删除数据、迁移或权限扩大必须另行获得用户确认。

## 未来首个可交付物

不是“自动路由器”，而是一份 Phase 0 兼容性报告：候选模型、网关协议、任务循环、真实路由证据、上下文边界、Sol 基线、失败案例、成本测算及是否进入 Phase 1 的明确结论。
